            <p>We process only data strictly required for service delivery, user verification, and platform integrity:</p>
            <ul>
                <li><strong>Account & Entity Identifiers:</strong> Name, professional email address, corporate entity name, telephone contact, and authentication tokens.</li>
                <li><strong>Technical Telemetry:</strong> Anonymized operating system metadata, crash logs, and localized IP headers strictly utilized for malicious traffic mitigation and bot defense.</li>
                <li><strong>Document Data for Processing:</strong> Inputs submitted for automated processing (e.g., invoices, real estate spreadsheets, text prompts).</li>
            </ul>
    
            <h3>5.2 Generative AI & Model Training Commitments</h3>
            <p>We mandate strict multi-tenant data sovereignty:</p>
            <ul>

We do <strong>not</strong> use proprietary tenant data to train public foundational AI models without prior written consent.</li>
                <li><strong>Data Isolation:</strong> Tenant records are isolated logically and cryptographically, preventing data contamination across client organizations.</li>
